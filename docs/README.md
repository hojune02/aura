# aura Website

This folder is a static website for App Store Connect links.

Recommended fast deploy:

1. Push this repository to GitHub as `hojune02/aura`.
2. Open the repository settings on GitHub.
3. Go to Pages.
4. Set the source to the `main` branch and `/docs` folder.
5. Use these App Store Connect URLs:
   - Privacy Policy URL: `https://hojune02.github.io/aura/privacy/`
   - Support URL: `https://hojune02.github.io/aura/support/`

If you deploy to another host, update `aura/Models/AppLinks.swift` and `aura/AppStore/privacy_policy.md`.
